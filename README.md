Features

User Registration & Login: Students can register and log in to apply for scholarships.

Scholarship Listings: View and filter various scholarships based on eligibility.

Application Submission: Submit scholarship applications with required documents.

Admin Dashboard: Admins can manage scholarships, review applications, and approve/reject them.

Notification System: Users receive notifications on application status.

Responsive Design: Fully responsive and accessible from all devices.

Technologies Used

Frontend:

React.js: For building interactive user interfaces.

Tailwind CSS: For fast and responsive styling.

React Router: For client-side routing.

Backend:

Node.js: For server-side operations.

Express.js: For building RESTful APIs.

MongoDB: For database management.

Others:

JWT Authentication: For secure login and session management.

Firebase: For authentication and hosting (if used).

Axios/Fetch API: For API requests.

How It Works

User Registration: Students create an account using their email.

Browsing Scholarships: After logging in, students can browse and filter scholarships.

Application Process: Users fill out forms and upload necessary documents.

Admin Review: Admins review submitted applications and update their statuses.

Notifications: Students get real-time updates on their application status.


Deployment

Frontend: Deployed on Vercel/Netlify.

Backend: Hosted on Render/Heroku.

Database: MongoDB Atlas for cloud database management.
